# Data Structures and Algorithms
Illustrative Study Buddy syllabus. Original sample material, for demonstration. Course code DEMO201.

## Module 1: Linear structures (11 hours)
- Arrays and linked lists
- Stacks and queues
CO1

## Module 2: Trees (12 hours)
- Binary search trees
- Tree traversal
CO2

## Module 3: Graphs (13 hours)
- Breadth-first search
- Dijkstra's algorithm
CO3

## Module 4: Algorithms (12 hours)
- Merge sort
- Binary search
CO4

## Course outcomes
CO1 Select a linear structure based on operations and costs.
CO2 Trace searches and traversals in trees.
CO3 Find graph paths and interpret shortest-path constraints.
CO4 Trace sorting and searching algorithms and analyze complexity.

## Textbooks
Introduction to Algorithms, Thomas H. Cormen and coauthors
